# Stammbaum für Home Assistant

Add-on-Repository für **Stammbaum**, einen Familienstammbaum mit Personen, Fotos, Ereignissen,
Quellen sowie den Ansichten Stammbaum, Ahnen, Zeitstrahl und Weltkarte.

## Installation

1. In Home Assistant: **Einstellungen → Add-ons → Add-on Store**, oben rechts **⋮ → Repositories**.
2. Diese Adresse eintragen und hinzufügen:
   `https://github.com/vo5tr0/stammbaum-homeassistant`
3. Das Add-on **Stammbaum** öffnen, **Installieren**, dann **Starten**.
   „In Seitenleiste anzeigen“ einschalten.

Angemeldet wird mit den Home-Assistant-Benutzern, es gibt kein eigenes Login.
Details stehen in der Dokumentation des Add-ons.

Unterstützt: 64-Bit-Systeme (amd64, aarch64, z. B. Raspberry Pi 4/5 mit HA OS, Home Assistant Green/Yellow, x86-PCs).
